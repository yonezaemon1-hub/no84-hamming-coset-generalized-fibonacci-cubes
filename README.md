# Research No.84 — Hamming-coset perfect codes in generalized Fibonacci cubes

Ryutaro Yonezu · 24 November 2026 · preprint v1.0

An explicit 1-perfect code is constructed for every integer p ≥ 3 in Q_(2^p−1)(1^s), where s = 3·2^(p−2)−1. The same code works for larger forbidden run lengths. The manuscript contains the proof and scope limits.
